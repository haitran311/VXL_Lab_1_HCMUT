# Microprocessor Lab 1: STM32 GPIO & LED Control

## Giới thiệu
Kho lưu trữ này chứa mã nguồn C và các file mô phỏng phần cứng cho Lab 1 môn Vi xử lý - Vi điều khiển (Trường Đại học Bách khoa – ĐHQG-HCM). 
Mục tiêu của bài thực hành là làm quen với việc cấu hình GPIO trên vi điều khiển STM32 và thiết kế các máy trạng thái (FSM) để điều khiển ngoại vi.

## Môi trường và Công cụ
* **Vi điều khiển:** STM32F103C6
* **IDE:** STM32CubeIDE
* **Mô phỏng phần cứng:** Proteus 
* **Ngôn ngữ lập trình:** C (Sử dụng thư viện HAL)
